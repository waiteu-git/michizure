# RevenueCat を Michizure（Web）に載せられるか — 実測（2026-09-04）

統合ハブ経由の指示「**Web で成立する統合方式があるのか、あるならどれかを先に確定**」への回答。
⚠ 噛み合わなければ組込方式も見積りも変わるため、**推測ではなく一次情報と実測**で確かめた。

## 結論: 成立する。ただし見積りを変える事実が2つある

### ✅ 成立の根拠

- **RevenueCat Web Billing が存在する。** Web SDK（`@revenuecat/purchases-js`）は
  **フレームワーク非依存**で、素のブラウザ JS/TS から使える（公式ドキュメント）
- 課金基盤は **RevenueCat Billing / Stripe Billing / Paddle Billing** から選べる。
  2026-04-17 に Stripe Billing と Stripe Managed Payments（Merchant of Record）が
  Web の購入フロー全体で使えるようになった
- **匿名 ID をサポートする**（`Purchases.generateRevenueCatAnonymousAppUserId()`）＝
  アカウント登録を持たない Michizure と噛み合う余地がある
- ペイウォールは**モーダル**（`presentPaywall()` で指定要素に埋め込む）＝
  別ドメインへ飛ばされないので、部屋の状態を保ったまま出せる

**実測**: 実際に依存に入れて、このリポの esbuild でブラウザ向けにバンドルできることを確認した。
Node 固有 API（`require` / `process` / `__dirname`）への参照は **0件**。

### ⚠ 事実1: SDK が重い（アプリ全体の約21倍）

| | gzip 後 |
|---|---|
| いまの Michizure（初回に読む分） | **10,864 B** |
| RevenueCat Web SDK 単体 | **227,038 B** |

> 🔴 **2026-09-05 訂正**: 旧記載の 9,260 B は誤り。`index.html + app.js` だけを数え、
> esbuild の chunk 4本を全部「遅延」と仮定していたが、`chunk-IWUKCSCV.js`（暗号・状態の
> 共有コア 1,430 B）は**静的 import** で初回に読まれる。`--splitting` は遅延用だけでなく
> **共有 chunk も作る**。倍率も 24倍 → 約21倍 に変わる。（`gzip -9` で再実測）

**既定で読み込むと、「旅先は電波が悪い前提＝軽さ」という差別化の軸そのものを壊す。**

⇒ **遅延読み込みが必須**（単語リストと取り込み機能で既に使っている手法）。
有料機能の導線を押した人だけが運ぶ形にすれば、基本の体験は 11KB のまま保てる。
**この前提が崩れる組込方（初期化を起動時に走らせる等）は採れない。**

### 🔴 事実2: 「誰に対して課金するのか」が未定義（設計の中核に触る）

RevenueCat は `appUserId` を必須とする。一方 Michizure は**アカウントを持たない**設計で、
単位は「人」ではなく**部屋**（複数人・複数端末で共有される）。組み合わせは3通りしかない:

| 課金の帰属先 | 何が起きるか |
|---|---|
| **端末**（匿名ID） | 機種変で課金を失う。同じ人が別端末で使えない。**部屋は共有されるのに課金は共有されない**という捻れが出る |
| **部屋** | サーバーが「この部屋は課金済み」を持つ＝**保持するデータが1項目増える**。プライバシーポリシーと法務照会の前提が動く |
| **人**（アカウント新設） | **設計の中核（アカウント無し）を壊す**。ゲート②の規約類も書き直しになる |

⇒ **これは実装の判断ではない。** どれを選んでも、①法務照会で申告済みの「サーバーが持つもの」
②プライバシーポリシーの記述 ③電気通信事業法の「営む」該当性（対価徴収で判定が変わる）の
いずれかに触れる。**ビジネスハブと統合ハブの裁定が要る。**

⚠ なお **サンドボックス検証だけなら踏まない**（誰にも課金を提供しないため）。
先に進められるのは「組込と検証」までで、**帰属の設計は裁定が要る**。

## ユーザーの手が要るもの（エージェントは行わない）

- RevenueCat のアカウント作成
- 課金基盤の選択（RevenueCat Billing / Stripe / Paddle）とその側のアカウント
- 商品・価格の登録
